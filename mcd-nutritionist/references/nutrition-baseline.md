# 营养基线：标准、算法与点餐策略

## 1. 参考标准

中国食品标签营养素参考值 NRV（GB 28050-2011，成人每日）：

| 营养素 | NRV | 本 skill 采用的单餐参考（按餐次比例折算） |
|---|---|---|
| 能量 | 8400 kJ（≈2000 kcal） | 午餐 700 / 晚餐 600 / 早餐 500 kcal 量级 |
| 蛋白质 | 60 g | 减脂期建议 1.6-2.2 g/kg 体重/天 |
| 脂肪 | ≤60 g | 供能比 25-35% |
| 碳水化合物 | 300 g | 供能比 50-60% |
| 钠 | 2000 mg（WHO 建议 <2000mg） | 单餐 >700mg 即需提示 |
| 钙 | 800 mg | 单餐 240-280mg（午餐/晚餐） |

餐次占全天比例：早餐 25%、午餐 35%、晚餐 30%、加餐 10%、未指定 33%。

## 2. 目标热量算法

- BMR（Mifflin-St Jeor）：男 `10×体重kg + 6.25×身高cm − 5×年龄 + 5`；女 `10×体重kg + 6.25×身高cm − 5×年龄 − 161`。
- TDEE = BMR × 活动系数：久坐 1.20 / 轻量 1.375 / 中等 1.55 / 高强度 1.725 / 运动员 1.90。
- 目标热量 = TDEE × (1 + 目标调整)：减脂 −20%、维持 0、增肌 +10%。
- 单餐目标 = 每日目标 × 餐次比例；也可由用户直接指定（如 500 大卡套餐）。
- 蛋白质目标 = 体重 × 系数（减脂 2.0、维持 1.5、增肌 1.8 g/kg）× 餐次比例。
- 脂肪目标按 28% 供能、碳水按 50% 供能反推。

## 3. 组合推荐评分

满足硬约束后才参与评分：

- 热量偏差 ≤15% 且不超过目标 105%（500 大卡套餐必须 ≤500 的硬约束即来自此）
- 至少有一件蛋白质 ≥8g 的餐品（避免"甜品 + 饮料"式空热量组合）
- 蛋白质 ≥ 目标的 60%
- 钠 ≤ 本餐上限的 150%

评分权重：热量贴合 30% + 蛋白质达成 30% + 钠控制 20% + 供能结构 10% + 钙 10%。
用 `--no-strict` 可关闭硬约束；若严格模式下无解，会自动降级为近似结果并提示。

## 4. 麦当劳点餐营养策略

**优先选**
- 非油炸肉饼：原味板烧鸡腿堡、板烧鸡腿麦满分（双面煎制，脂肪显著低于油炸款）
- 高蛋白密度：薄皮脆汁鸡（带骨里脊）、薄皮焦香 V 翅、麦乐鸡（去皮更佳）
- 补钙与蛋白：纯牛奶、热/冰牛奶、奶铁、卡布奇诺
- 加纤维：玉米杯、苹果片、鲜蔬类

**谨慎选**
- 油炸精制碳水：薯条（热量密度最高，饱腹感弱于等量薯类）
- 含糖饮料：可乐/雪碧/柠檬红茶，中杯即 100-180 kcal、25-40g 糖；改无糖可乐、鲜萃咖啡、锡兰红茶、纯悦
- 甜品：麦旋风/新地/雪冰单杯 200-360 kcal，糖负荷高
- 高钠：安格斯系列（单堡钠 900-1400mg）、酥酥多笋卷、蒜了吧风味脆汁鸡

**组合技巧**
- 先定蛋白质锚点（一个汉堡或一份鸡肉类），再用小食/饮料补齐剩余热量额度
- 减脂时把薯条换成玉米杯（省 150-250 kcal），把含糖饮料换成无糖（省 100-180 kcal）
- 增肌时优先"汉堡 + 牛奶/奶铁"组合，兼具蛋白与钙
- 官方 500 大卡组合（果然多肉、"苹板"支撑 Pro、专"薯鱼"你、绝代双翅、牛气满满、蜜汁快乐）已按 ≤500 kcal 设计，可直接引用

## 5. 表达与免责

- 数值说明：官方营养数据每 5 年由认可的实验室测定更新；实际值可能因原料批次、产地、季节、加工与烹制差异略有出入。
- 减重/增重速率、血脂血压等健康指标不在本 skill 的判断范围内。
- 糖尿病、肾病、高血压、痛风等慢病人群及孕妇、儿童，只给通用原则（控糖/控钠/控嘌呤/保证蛋白），并提示以医生或临床营养师意见为准。
- 任何情况下不声称"治疗""治愈""保证效果"。
